Odd Bits

Privacy policy

Effective 27 October 2026

Odd Bits is a small video channel on YouTube, TikTok and Instagram. This page explains what data this website and the Odd Bits Post Office app handle. In short: we don't collect data about you.

This website

This is a static website with no cookies, no analytics, no tracking and no forms. It is hosted on GitHub Pages; GitHub may log technical data such as IP addresses to run and protect the service, as described in the GitHub privacy statement. The page loads its font from Google Fonts, under Google's privacy policy.

The Odd Bits Post Office app

"Odd Bits Post Office" is a private tool that the channel's owner runs on their own computer. It uses Google sign-in only for the Odd Bits YouTube channel, to:

  • upload Odd Bits' own videos to the Odd Bits channel (youtube.upload), and
  • read the view, like and comment counts of those videos (youtube.readonly).

It is not offered to anyone else and does not access other people's Google or YouTube accounts. The sign-in tokens are stored only on the owner's computer. They are never sold, shared or used for advertising, and no data from Google APIs is transferred to third parties.

The Odd Bits Post Office's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

On YouTube, TikTok and Instagram

When you watch, like or comment on Odd Bits videos, the platform you use processes that data under its own privacy policy. Odd Bits only sees the totals and public comments the platforms show to every channel.

Contact and your rights

Questions, or a request about your data under the GDPR: oddbits02@gmail.com. You can also revoke the Post Office's access to a Google account at any time on myaccount.google.com/permissions.

Changes

If this policy changes, the new version will be posted on this page with a new date.
